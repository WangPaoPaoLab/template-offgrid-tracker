# UI 适配器交接契约

2026-11-14。这里列的是前端内部适配方法，不是新增服务器端点。当前 `alignment-model.js` 的实现全部为 `kind: demo`，不进行真实网络、BLE、账号或地图文件操作。

## 产品与数据约束

- product.key 是网页内的目标引用；真实接入时须解析到 product.id / controlDeviceId / gatewayDeviceId，不能发送显示名代替 Device `$id`。
- 产品类型、具体型号、固件版本、构建标识和能力分别保留。演示网关 / 聊天控制器的泛用型号不证明某硬件 SKU 获得了所有驱动地区和带宽的认证。
- BLE 状态、远端网络状态、云服务状态独立。GATT connected 不等于 ready；云端在线需要有效会话与服务核验。退出账号不能顺带断开本地聊天。
- nodeId / cloudDeviceId / serial / nodeNumString 分开；大整数地址使用字符串。alias 是本地别名，name 是共享记录名称，hardwareName 不是这两个编辑操作的副作用。
- 观测携带 value、unit、sampleAt、receivedAt、source、validity。信号附 reporterId / peerId；位置附 coordinateSystem。示例电压为历史云缓存，不表示离线 SDK 的电池解析缺口已经修复。
- 能力采用 true / false / null，分别代表支持 / 不支持 / 未确认。未确认时不能自动生成数值或开放有实际副作用的控制。示例保留 GPS_ONLY 无 ADC、60000ms / 0 固定配置范围。

## 配置与异步操作

每条配置事务独立绑定目标与请求。新草稿可以在旧命令执行时保存；旧命令确认只更新对应的实际确认值，不覆盖新草稿，并维持“待应用”。切换产品或页面不能把异步回调写到新目标。刷新后保留上次确认缓存，但不能自动认定当前硬件仍是该值。

国家、信道、频率、带宽是合法元组。保持九地区 / 188 条完整源目录；实际可写集合由固件、硬件 SKU 与确认的区域许可限制。频率来自选定信道，不能用任意频率输入框绕开驱动表。Mesh ID 和密码按 UTF-8 字节校验；空密码保持空。

## 围栏与坐标

保存时将“此网关现有节点”解析成明确 ID 快照，不序列化空数组给云端。当前云端空数组表示整个 Profile，语义不同。新加入节点不自动加入旧快照；动态范围另定义。

本机保存不等于开始监测；同步成功与实际执行端分别标明。云端断网不虚构设备离网判断。示意图和本机几何工具只用于规格验证；目前云端按位置样本判断区域内 / 外，并非已实现严格穿越事件、漂移抑制与事件去重。

位置元数据与围栏采用明确一致的坐标体系。未来接高德等底图时，在显示适配层同时转换节点与围栏，保留原始坐标及体系，避免反复加偏。原版固定斯德哥尔摩和下载排队问题见 `../ui-handoff/reference/backend_alignment/MAP_AND_GEOFENCE_REVIEW.md`。

## 消息与能力范围

logicalMessageId 保持不变，attemptIds 记录发送尝试；消息含产品、会话、发送方、接收方、kind 与附件。公开频道的 38801 / 38803 / 38805 / 38807 / 38809 是通信端口，不是射频频道。广播只显示 Sent。

基线模式图片发送、独立已读、密码与重置、围栏同步以及未确认的配置读回受限。完整提案保留交互，但只代表产品目标。模式切回基线会撤销未来能力产生的已读 / 围栏监测 / 当前配置标记；本地媒体历史仍保留。

SDK 0.1.35 的 Android 语音使用 Ogg/Opus 或 3GP/AMR-NB，具体取决于平台版本；浏览器 MediaRecorder / 任意音频文件不能直接视为跨设备可用格式。8MB / 60 秒 / 240 UTF-8 字节是本展示板保护限制，生产应另定传输预算。

## 2026-11-14 设置与手机 HaLow 配置更新（优先于历史描述）

- 根导航为“设备 / 设置”，中心距约136 CSS px（桌面手机框），两入口各108×48，窄屏自适应；产品详情继续隐藏根导航。设置一级严格六项：账号、HaLow、通知、通用、帮助、关于。原顶部账号登录卡片收进“账号”，登录功能未删。聊天仍仅从产品卡片进入。
- `networkProfile={id,config,revision,updatedAt}` 是手机配置。`saveNetwork()` 可在未连接状态校验并保存，不创建设备应用结果；`pendingApply` 固定保存时的配置与版本，选设备、确认后才下发。不同设备的 desired / applied / cachedApplied、请求和配置版本独立。读取设备配置只更新设备记录，不覆盖手机草稿。旧版每设备配置保留，不随意选一个迁成全局配置。
- 仍完整保留 AU26 / CA48 / EU5 / GB7 / IN3 / JP12 / KR16 / NZ23 / US48，共9地区188条驱动记录。地区与带宽切换联动合法信道，中心频率只读。没有 Auto=0：已核对原 App 提供0选项，但固件 `halow_provisioning.c` 拒绝0，不能把它展示成已支持。发射功率、跳数等尚未核实产品级写入范围，不提供虚构滑杆。
- `identify(device)` 为新增的前端模拟契约。扫描行只叫“附近设备”，通过连接后的 schemaVersion / deviceId / productType / modelId / firmwareRole / firmwareVersion / capabilities / radioTuples 确认产品。描述未知或读取失败不绑定错误产品。`review.html` 有对应失败场景。当前真实 SDK 只提供板卡 / transport / 固定 category 等信息，**不能证明已提供这份产品描述**，须由 App / SDK / 固件共同补齐。fixture 的9地区不是任何SKU的认证声明。
- HaLow 应用须符合已识别设备权限、radioWrite 和设备声明的地区/信道交集。手机保存、待发送、传输、设备确认、失败和过期是不同状态；没有可靠确认时不显示已应用。网页不发送真实射频指令。
- 通知偏好实际持久化并用于 `notificationPolicy/notifyEvent`。`receiveMessage` 在关闭提醒时仍保留消息，当前会话内不重复弹提醒。`keepteen:notification` 事件携带 sound / vibration 策略，原生工程须接 OS 权限、通知渠道、声音和振动；网页本身不宣称已接系统推送，也不会凭开关假装已有可靠围栏告警。
- 通用含语言、外观、单位、离线地图、存储。公/英制转换展示距离，围栏存储与几何参数仍用米。缓存清理需确认，仅回收图片/语音 blob 与预览，保留文字、别名、围栏和网络配置；网页会话媒体不是原生持久文件管理。
- 聊天产品设置含聊天昵称，不再默认“离线领队”；账号 OTP / 密码能力边界不变。12语言每语言457条，全部离线完整翻译。
- `ui_halow` 是 H＋无线波纹的自绘细线功能图标，**非 Wi-Fi Alliance 官方标志或认证声明**。菜单统一显示 HaLow，不使用蜂窝四柱信号作为其入口。

原生还需把网络口令存放至平台安全存储；本地网页版仅用于展示，勿输入真实生产口令。品牌、素材、状态和交互可复用，模拟适配器不可当生产后端。
