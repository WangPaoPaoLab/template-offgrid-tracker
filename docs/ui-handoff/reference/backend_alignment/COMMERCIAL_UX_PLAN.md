# KEEPTEEN 消费级 App 商业化体验设计计划

日期：2026-11-14。状态：部分落地。已按用户要求整理网页默认入口、消费级文案与页面分工；其他内容仍为目标计划，原生 App、SDK、固件及云端尚未实施。

纠正记录：本文件曾提出的全局聊天入口已撤回；它违反了用户已确认的双 Tab 与独立聊天产品要求。信息架构以 [用户需求基线 R01–R05](../00_USER_REQUIREMENTS.md) 为准，不能把“商业化优化”当成改变产品归属的授权。

## 1. 产品目标与设计边界

面向养殖管理用户与离网通信用户，提供可以理解、可以恢复、状态可信的设备使用体验。首次打开就知道如何添加设备，日常使用快速查看项圈与聊天，异常时知道影响和下一步。

本轮主线：项圈网关与节点、聊天设备与会话、账号、无线设置、地图管理、诊断。水阀与摄像头保留产品卡片，不开发控制、视频或图库内页；雷达只预留类型扩展结构，不创建虚假设备。

网页继续作为可交互的设计与接口规格展示板。演示标识与场景切换放在手机展示区域之外；生产 App 不出现开发模式开关。网页模拟回执、下载、账号或围栏执行，不能成为原生链路已完成的验收证据。

能力依据为同目录 BACKEND_CAPABILITIES.md、BACKEND_RESOURCE_SNAPSHOT.json、MAP_AND_GEOFENCE_REVIEW.md，以及 ../web_prototype/ADAPTER_CONTRACT.md。清单基于固定源码与 SDK 0.1.35 的盘点，不代表生产服务或硬件已联调通过。

## 2. 导航与页面责任

根导航保持两个 Tab：设备、我的。聊天是独立硬件产品，通过首页聊天卡片进入；聊天产品和会话页隐藏根导航，返回设备首页后恢复双 Tab。

| 位置 | 主任务 | 进入后的内容 |
| --- | --- | --- |
| 设备 | 找到、添加和管理产品 | 紧凑双列卡片、附近设备搜索、产品详情 |
| 设备 → 聊天产品卡片 | 使用该产品的公共频道与队友会话 | 当前聊天设备、频道抽屉、会话、消息媒体；属于设备内页，不是根导航 |
| 我的 | 身份、账号和应用级设置 | 账号与本地身份、无线与网络、离线地图、偏好、帮助、诊断、关于 |

首页聊天卡片进入该设备对应的聊天空间；从会话返回该产品的频道 / 队友列表，再返回设备首页。聊天页顶端的小设备入口管理该聊天硬件。未绑定聊天设备时展示连接指引，不能显示虚构好友。

设备状态与设备操作位于设备详情；公共频道切换位于聊天；个人中心不再罗列项圈与聊天的连接卡片。无线设置统一入口放“我的”，进入后必须先明确目标设备；设备详情可跳转到同一份设置，避免两套配置。

## 3. 首页与品牌表达

沿用现有冷白与纯黑主题，默认跟随系统，并可手动选择。浅色底 #F5F5F7、卡片白色；深色底 #000000、卡片 #1C1C1E、细分层 #2C2C2E。灰色细线产品图局部使用 KEEPTEEN 橙色，主要按钮黑白。异常用红色及明确文字，状态不只依赖颜色。不引入绿色主色或大面积模糊。

完整品牌 Logo 放启动页与关于页；首页通过橙色细节、图标线条、字体层级和留白表达品牌，不重复放 Logo、口号和连接摘要。

首页保持标题、添加按钮、紧凑双列产品卡片。卡片仅显示线条产品图、用户名称、一行主要状态，以及必要的快捷操作。规格阶段以手机宽度约 390px 下卡片高 140–160px 为起点，长名称、大字体与多语言允许增高，不裁切文字；触控区域至少 44pt。

产品实例使用稳定 ID，名称可修改。默认不生成第二个网关；用户确实添加多个网关后，以“东区网关 / 西区网关”之类名称区分，辅以“项圈网关”类型说明。卡片可显示“8 个项圈”；若只是历史数量，写明缓存状态。不能把节点数量当作在线数量。

未添加产品的生产首页显示添加引导；展示板可预览水阀、摄像头两张未开放卡片，标明“即将支持”，点击解释范围，不使用假开关。未来产品通过类型、实例、能力与详情路由扩展。

连接概况随产品卡片显示，进入产品后展开。确有当前任务被蓝牙关闭阻断时，可展示一条可操作的上下文提示，不重新放常驻的全产品重复连接面板。

## 4. 添加产品与完整生命周期

添加按钮 → 附近设备搜索 → 选中真实发现的主控 → 安全连接与确认 → 命名 → 完成。扫描页覆盖蓝牙关闭、权限拒绝、扫描中、无结果、连接超时、身份验证失败、用户取消和成功。已有产品再次被发现时进入或重连该实例，避免重复创建。

手机搜索主控网关与聊天设备；低功耗项圈从网关内部的“添加项圈”发现，不承诺手机 BLE 可直接发现所有项圈。硬件类型根据广播、服务与能力识别，不依靠设备名称猜测。

| 状态 | 页面表现与可操作行为 |
| --- | --- |
| 冷启动 / 未连接 | 空状态、产品配对入口、离线使用说明；不要求先登录云账号 |
| 主控已连接 / 空网络 | 明确主控已就绪；项圈页提供发现节点，聊天页提供频道监听和使用说明 |
| 活跃网络 | 真实节点、有效遥测、对应目标的会话与回执 |
| 断开 / 缓存 | 保留历史数据并显示时间；连接按钮指向具体设备，不把缓存写成实时 |
| 仅云端可用 | 仍可按权限查看云端数据；说明本地蓝牙功能不可用 |
| 权限受限 / 部分失败 | 保留可用内容与输入，说明受限操作，提供重试或联系管理员入口 |

## 5. 项圈产品内部

项圈卡片 → 网关工作台，内部为“项圈 / 地图 / 围栏”。顶端简短展示网关名称及当前访问路径，点开查看详细连接。多网关时允许明确切换目标，搜索、节点、配置与围栏随目标隔离；跨网关总览以后再作为独立功能设计。

- 项圈列表：名称或编号、近期上报、有效电量信息、必要异常。提供名称搜索、状态筛选、分页或增量加载；大规模设备不能一次全部渲染。
- 节点详情：重命名、最近上报、定位时间与来源、电池、HaLow 链路信号、地图定位、能力允许的采样设置。
- 本地别名立即保存在本机；修改共享名称需要权限与服务确认。两者使用不同说明，不能用名称代替设备 ID。
- 电量有已验证百分比才显示百分比；只有电压则显示 V，缺采样显示“此型号未提供”。信号显示该节点的实际链路来源，不用手机 BLE 信号冒充。
- 上报延迟依据型号周期和实际策略判定；休眠设备不能因超过固定 120 秒就统一标为失联。缺定位、位置过期和正常在围栏内是不同状态。

## 6. 地图与电子围栏

当前状态和可交给 App 工程师的实施清单见 [MAP_GEOFENCE_IMPLEMENTATION_HANDOFF.md](MAP_GEOFENCE_IMPLEMENTATION_HANDOFF.md)。本节为设计目标，不表示真实地图、离线下载和可靠围栏已接通。

地图位于项圈产品内部。首次进入优先适配当前网关下有效节点；没有节点时，在用户许可后定位到手机；两者都没有则显示定位引导和区域选择，不固定显示斯德哥尔摩，不伪造当前位置。

地图主操作：定位到我、查看全部项圈、图层、离线地图。点标记弹出节点摘要并可进详情；重叠节点聚合。位置过期显示时间与不同样式，手机位置和项圈位置明确区分。地图包管理属于应用级存储，可从地图快捷进入“我的 → 离线地图”。

近期先核查并修复现有 Organic Maps 下载链路及原生错误回传，不预设必须更换引擎。地图包具有区域、实际版本、大小、排队 / 下载 / 校验安装 / 完成 / 失败状态，支持原生能力确认后的取消、重试、删除和存储不足恢复。无网络时说明正在显示已下载或缓存的内容，未覆盖区域明确提示。

全球原始位置与围栏保留明确的坐标系；如引入中国地区底图，显示层对节点、手机位置和围栏使用一致的适配。换图层不能直接视为纠偏完成，需在深圳真机对照实测。底图来源、离线下载授权、署名、服务限额与费用在引入前核实；不将公共瓦片服务当作免费无限离线下载源。

围栏创建流程：选择区域 → 调整边界 → 选择适用项圈 → 选择进入 / 离开提醒 → 命名 → 保存与同步。默认优先圆形；矩形、多边形与椭圆在更多形状中保留，实际入口根据后端与执行端能力开放。

列表至少区分：本机草稿、待同步、同步失败、已在明确执行端启用、已暂停。已启用需显示“云端监测”或其他已验证执行端；保存成功不代表开始监测。告警显示项圈、围栏、事件时间、位置及查看 / 确认操作，确认必须有授权结果。

围栏事件设计要求：首次有效位置建立状态；真实内外变化才触发穿越事件；按精度、采样间隔与实测结果设计边界缓冲和确认策略，避免 GPS 漂移反复报警；重复事件去重；失联单独提醒，不能解释为围栏内安全。该逻辑为目标方案，当前云端样本判断需要补改和验证。

借鉴 Meshtastic 当前 Android 源码的地图点选、聚合、简单围栏编辑与首次位置基线。其 App 侧计算不证明我们的网关具有离线执行能力；手机后台、网关独立和云端判断须分别定义和验收。

## 7. 聊天体验

文字为主输入，图片与语音为清晰的次级入口。支持输入保留、图片预览与取消、录音时长与取消 / 重录、附件上传或传输进度、发送失败重试。是否支持压缩、媒体大小和录音时长由无线吞吐、编码与 SDK 联调确定，不沿用网页限制作为生产规格。

会话区分私聊与公共频道。私聊状态为发送中、已发出、已送达、失败；独立已读协议具备且对端支持时才显示已读。公共广播不显示全员送达或已读。重试关联同一逻辑消息，不能重复冒出多条气泡。

聊天页展示当前聊天设备；手机到设备断开、远端暂无响应、没有互联网分别解释，只提示实际影响。公共频道从聊天页切换，与无线中心频率分开命名。离线文字和语音不以登录云账号为前提。

文字已有基础；语音已有 SDK 基础仍需 App 接入与互通验收；图片、独立已读需要补协议与持久化。目标设计保留完整流程，现有能力演示明确受限，生产不展示不可兑现的功能按钮。

## 8. 我的、无线设置与诊断

我的分为账号与本地身份、无线与网络、离线地图、应用偏好、帮助与支持。关于和诊断各自独立入口，长表单与诊断页使用全屏页面，简单选择与确认使用底部抽屉，避免所有内容挤进可滚动弹窗。

账号同时设计邮箱验证码、密码登录与找回密码，是否在发布版开放取决于服务配置及完整客户端链路。当前已确认的是邮箱验证码，不标成手机短信验证码；密码服务当前关闭。允许不登录使用本地功能。退出账号不默认清空本地设备与消息，切换账号不能泄漏上个账号的云端设备缓存。

本地身份与云端账号分开解释；展示公开标识而非私钥。成员、管理员等权限按实际后端授权决定，前端隐藏按钮不替代服务端校验。分享、解绑、恢复出厂与删除记录分别说明后果；硬件解绑与云记录删除不能合并成假定的一步成功。

无线与网络：先选目标设备，再展示能力允许的国家 / 地区、网络名称与密钥及连接模式；高级选项折叠，保留带宽、信道、功率、跳数等实际受支持字段。用户切换地区不能绕开硬件 SKU 或许可限制；不存在的字段不强加到固件。

沿用已核对的完整驱动目录与能力过滤，不缩减成少数国家演示；驱动支持地区不等于产品销售认证。频率由合法地区 / 信道 / 带宽组合决定，不提供任意中心频率输入。计划不新增频率表，实际变更前再次核对目标固件。语言选择独立于射频地区，保留现有 12 语言，并逐项核对计划销售国家的语言覆盖。

配置显示编辑草稿、待下发、等待设备接收、已确认生效、失败与超时。参数更改可能导致断链时，提交前说明影响和恢复方式。未确认读回时写“尚未确认”，不把命令入队当成生效。

关于：适当尺寸 Logo、App 版本、帮助链接、隐私与条款、适用平台的版本检查入口。设备型号和固件放设备详情；诊断允许按用户选择的设备查看这些信息，但不再自动堆叠所有设备卡片。

诊断：按问题选择设备，检查权限、蓝牙会话、数据接收、可选云端访问与地图包状态，提供用户可理解的结果和下一步。需要时导出经过脱敏的日志，排除账号令牌、私钥与网络密码。云端未登录不能被归为离线通信故障。

## 9. 设计与接口交付

每个页面一起交付：主要任务、入口与返回路径、字段来源、空状态、加载 / 失败 / 重试、权限、数据时间与能力限制。接口契约标记“已有调用 / 需适配 / 需新增 / 待确认”，不把设计适配器命名当成已存在的服务器接口。

设备、节点、配置请求、会话和围栏均绑定稳定 ID 与目标。异步返回检查目标和版本；切换网关后旧请求不能覆盖新页面。地图与位置有来源及坐标体系；消息回执区分事件；配置区分期望值和确认值。真实状态由可追溯的服务或硬件结果驱动。

可交付成果为：页面结构与流程、本网页可交互展示、状态与能力矩阵、接口字段与错误处理约定、需要 App / SDK / 固件 / 云端配合的开发清单，以及分阶段验收记录。当前文档是计划，不是上述实施成果已完成的声明。

## 10. 实施顺序与商业发布门槛

| 阶段 | 工作 | 阶段完成依据 |
| --- | --- | --- |
| A：确认方案 | 确认导航、设备入口、状态文案和首版功能边界 | 用户确认本计划及需要调整之处 |
| B：网页交互规格 | 调整首页、连接流程、设备内页、关于与诊断，再完善地图围栏、聊天及个人页 | 冷启动、空网络、活跃与异常流程可逐项演示；所有语言及深浅色可用 |
| C：原生能力对接 | 设备归属、权限、真实文字 / 语音、节点配置、地图下载与错误处理 | 使用指定 App / SDK / 固件版本的真机记录，不以网页动画验收 |
| D：新增能力闭环 | 密码与恢复、聊天图片、已读、围栏管理与执行端协议 | 各功能的服务授权、持久化、失败恢复与跨设备测试通过后独立开放 |
| E：发布验收 | 地区与型号支持矩阵、隐私权限、多语言、性能、可访问性与升级恢复 | 每项宣传能力均有实测证据；不支持能力明确隐藏或解释 |

先验证核心路径：未登录添加主控 → 发现项圈 / 进入聊天 → 看到真实上报 / 对端消息 → 断开与重连后数据不混乱。与其同时开放全部入口，更应确保每个已发布能力都有完整结果和恢复方式。

发布前必须覆盖：两网关隔离、休眠项圈、无电量型号、GPS 缺失与过期、中国坐标实测、地图下载 0% 与取消恢复、手机无互联网、云端不可用、权限撤销、媒体超时、收发双方能力差异、大字体与长译文。围栏相关宣传必须写清执行端、定位与通信条件；未验证网关离线执行前不得承诺“关机断网也持续报警”。
